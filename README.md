# Hotel-Miranda-Dashboard-Backend

**Licencia:** MIT

## Estado  
Terminado

## Descripción  
Backend en TypeScript (100 %) para el panel de gestión del Dashboard Hotel, incluyendo controladores, servicios, middleware, validaciones, tests y documentación Swagger.

## Tecnologías y herramientas  
- **Lenguaje:** TypeScript (100 %) 
- **Documentación APIs:** Swagger (`swagger.ts`)
- **Tests:** carpeta `tests/`
- **Configuración:** `package.json`, `tsconfig.json`, `.gitignore` 
- **Arquitectura típica:** separación de capas: controladores, servicios, middleware, interfaces y datos
